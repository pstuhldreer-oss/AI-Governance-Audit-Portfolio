# AI Governance & Agentic AI Audit Portfolio

## Aviation MRO Case Study

**Author:** Paweł Stuhldreer  
**Status:** In development

## Project Objective

This project demonstrates the practical application of AI governance, risk management and audit controls to a simulated AI agent supporting aviation Maintenance, Repair and Overhaul (MRO) operations.

## Project Scope

- AI governance and risk assessment
- ISO/IEC 42001:2023 management system controls
- EU AI Act applicability assessment
- Agent identity, authorization and delegation
- Human oversight and accountability
- Audit logging, traceability and evidence
- Security testing and internal audit

## Project Methodology

1. Define the simulated AI system and its intended purpose.
2. Identify relevant risks and applicable requirements.
3. Design preventive, detective and corrective controls.
4. Implement and test a demonstration AI agent.
5. Collect audit evidence and document findings.
6. Prepare the final audit report and recommendations.

## Frameworks and References

- ISO/IEC 42001:2023
- Regulation (EU) 2024/1689 (EU AI Act)
- OWASP AI Security and Privacy Guide
- NIST AI Risk Management Framework

## Disclaimer

This is an independent educational portfolio project based on fictional scenarios and synthetic data. It is not an official OWASP project or an audit of a real aviation organization. The simulated system will not make operational airworthiness decisions.
