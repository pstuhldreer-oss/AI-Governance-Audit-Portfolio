# AI System Description

## 1. General Information

**System Name:** MRO Maintenance Support Agent
**System Type:** Agentic AI – Decision Support
**Industry:** Aviation Maintenance, Repair and Overhaul (MRO)
**Project Type:** Simulated educational case study
**Document Status:** Draft v0.1
**Author:** Paweł Stuhldreer

## 2. Purpose of the AI System

The MRO Maintenance Support Agent is a simulated AI system designed to support administrative analysis of fictional aircraft maintenance reports.

The agent identifies reported issues, categorizes information, retrieves relevant synthetic reference materials and prepares draft recommendations for human review.

The system does not perform aircraft maintenance, certify airworthiness or independently authorize operational decisions.

## 3. Intended Users

- Maintenance planning personnel
- Quality assurance specialists
- Technical documentation coordinators
- Authorized human reviewers
- AI governance and internal audit personnel

## 4. Core Functionalities

1. Receive fictional maintenance reports.
2. Extract and categorize reported issues.
3. Retrieve information from an approved synthetic knowledge base.
4. Generate a draft administrative summary.
5. Flag uncertainty and missing information.
6. Submit recommendations for human review.
7. Record relevant actions in an audit log.

## 5. Agent Architecture

The demonstration system will include:

- Input validation component
- AI reasoning component
- Controlled document retrieval tool
- Authorization and access control layer
- Human approval checkpoint
- Audit logging mechanism

These components represent the target architecture and have not yet been implemented or tested.

## 6. Data Sources

Only fictional and synthetic data will be used.

Permitted data:
- Synthetic maintenance reports
- Fictional technical reference documents
- Simulated user roles
- Test scenarios and audit logs

Prohibited data:
- Real aircraft maintenance records
- Confidential organizational documents
- Personal data from operational systems
- Restricted technical documentation

## 7. Human Oversight

All generated recommendations require human review.

The agent cannot:
- Release aircraft to service
- Approve maintenance work
- Modify operational maintenance records
- Issue binding technical instructions
- Execute actions in production systems

## 8. Preliminary Risk Areas

- Hallucinated or inaccurate information
- Unauthorized access to documents
- Prompt injection
- Excessive agent permissions
- Incomplete audit trails
- Unclear human accountability
- Incorrect or outdated source information
- Inadequate human oversight

## 9. Governance and Compliance References

The project will assess relevant controls and requirements using:

- ISO/IEC 42001:2023
- Regulation (EU) 2024/1689 (EU AI Act)
- NIST AI Risk Management Framework
- OWASP AI security guidance

Applicability of legal obligations will be assessed separately. Inclusion of a framework does not imply that every requirement applies to this simulated system.

## 10. Planned Audit Activities

1. Define system boundaries and responsibilities.
2. Conduct an AI risk assessment.
3. Establish an AI control matrix.
4. Design and implement a demonstration agent.
5. Execute security and governance test scenarios.
6. Collect and evaluate audit evidence.
7. Prepare an internal audit report.

## 11. Project Limitations

This is an independent educational project using fictional scenarios.

The system is not connected to a real MRO environment and is not approved for aviation operational use.
